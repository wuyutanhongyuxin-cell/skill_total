## 二、算法说明

### 加权情感分（核心指标）

模型 `<model_id>` 对每条样本输出 5 维概率向量 `p = [p_NegPlus, p_Neg, p_Neu, p_Pos, p_PosPlus]`。本作业不取 argmax，而是采用等距加权：

```
sent_score = p · W       其中 W = [-2, -1, 0, 1, 2]
```

得到连续情感分 `sent_score ∈ [-2, +2]`，正数偏喜，负数偏哀，0 为中性。比 argmax 信息量更大，能区分"勉强 Neg"和"极端 Neg+"，并可作为热力图/地图/曲线的标量输入。

### <离散映射>（如朝代映射）

<语料中共 N 类实体>。`core/<map_module>.py` 提供 <M> 条硬编 dict，覆盖率 <%>，将<实体>映射到 <K> 个分组：
- <分组1>（<时段/范围>） · <数量> 位
- <分组2>（<时段/范围>） · <数量> 位
- ...

### <实体地理映射>（地图图专用，可选）

`core/<entity_geo>.py` 提供 <M> 条 `{实体: (lat, lon, 现代地名)}`，覆盖率 <%>（未覆盖 <N> 位：<列举>）。坐标取实体<出生地/主要活动地>的现代行政中心。

### 词云算法

<N> 条语料量<大/小>，故采用「<字级 / 词级 / 字+bigram 混合>」策略：
- 主字典：去虚词后的高频字 top 200
- 加权 bigram：高频双字组 top 30，权重 ×2 让"<例子>"在画面更显眼
- 不使用 jieba 默认分词（古文场景下会把"<例句>"切坏）

### <历时演变>（07 号图）

参考 Paper 3 (Evol) 的 **Diachronic n-gram frequency tracking**：

```
freq_norm(意象, 时段) = count(意象 in 时段语料) / total_chars(时段) × 1000
```

选 <N> 个关键意象分 <M> 主题组，追踪每千字出现频次随 <K> 个时段的演变曲线。

### <共现网络>（08 号图）

参考 Paper 3 (Evol) 的 **Word co-occurrence network**：

```
对每条样本取去虚词后字集合 S
对所有 (a, b) ∈ S × S 且 a < b，cooccur[(a, b)] += 1
保留 Top <N> 字之间且共现次数 ≥ <K> 的边
```

节点大小 ∝ 字频，颜色 ∝ 该字所在样本的情感分均值，边粗 ∝ 共现强度，布局用 networkx `spring_layout`（力导向）。
