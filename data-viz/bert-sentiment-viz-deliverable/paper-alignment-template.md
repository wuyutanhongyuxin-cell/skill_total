# 「对照参考文献」章节模板

> 这是设计说明.md 的第 IV 章。它是 BERT 情感分析作业类任务里**最容易被偷工减料**的部分——也是评分老师最在意的部分（证明你读过给的论文）。

## 为什么必须有这一章

教师给了参考论文 = 期待看到「用了什么方法 / 借鉴到哪张图」的明示对应。如果没有这一章：

- 评分老师无法判断你是否真读过论文
- 你的"参考"等于自说自话
- 即使方法上确实借鉴了，没 cite 就是抄袭嫌疑

## 三段式模板（每篇论文）

```markdown
### Paper X · <论文标题简称（不必引全名）>

**方法**：<一句话精炼方法>——用 LIWC / BERT / RDD / SCM / Diachronic n-gram 等专有名词点出方法骨架。

**本作业借鉴**：
- <借鉴点 1>（→ 对应到本作业 0X 号图 / 某个公式）
- <借鉴点 2>（→ ...）
- <借鉴点 3>（→ ...）
```

## 借鉴点写法（4 种合法形态）

### 形态 A · 方法直接复刻

```markdown
- **07 号关键意象朝代演变曲线** 直接复刻 Paper 3 的 Diachronic n-gram 方法，
  公式与归一化策略与原文一致（每千字频次）。
```

✅ 明确指向图 + 方法名 + 公式溯源。

### 形态 B · 视觉样式参照

```markdown
- **05 号朝代时间曲线** 直接对标 Paper 2 的 **lockdown trajectory** 风格 ——
  时间轴 + 重大事件（安史之乱 ↔ lockdown 实施日）的垂直阴影标注 + ±1σ 置信带。
```

✅ 明确指向图 + 论文 figure 风格名 + 类比结构。

### 形态 C · 模型/技术选型对齐

```markdown
- 模型选择：`ethanyt/guwen-sent` 即 BERT 在古文情感语料上微调的版本，
  与 Paper 2 的 BERT 路线一致。
```

✅ 说明你的工具选型沿用了论文的技术栈。

### 形态 D · 维度/坐标轴选择

```markdown
- **05 号** 用朝代分段背景而非连续公元年份 ——
  Paper 3 论证朝代是更符合古代文献分布的时间单元。
```

✅ 说明你的某个数据轴选择由论文论证支持。

## 反模式（绝不写）

❌ **只列标题不说借鉴**：
```markdown
- Paper 1: LIWC + Embedding Emotionality 政治语言研究
- Paper 2: Nature COVID 政府公告情感影响
- Paper 3: Evol 古典文学历时性词汇演变项目
```
这是"看过封面就说看过书"。

❌ **借鉴而不指向具体图/公式**：
```markdown
- 借鉴了 Paper 3 的方法做了一些时间序列分析。
```
"做了一些"是没指向。改成"07 号图复刻 Diachronic n-gram"。

❌ **泛化套话**：
```markdown
- 受 Paper 3 启发，我们也关注语言的历时演变。
```
"受启发"是空话，要说出具体借鉴了哪个公式/哪种图。

❌ **错位 cite**：cite 了论文但本作业根本没用它的方法——评分老师对论文熟，一眼看穿。

## 双向锚点（必做）

「对照参考文献」章节里**每个借鉴点** ↔ 对应图的**英文副标**「method ref: <Paper>」必须双向匹配。

例：
- 设计说明 IV § Paper 3 写「07 号复刻 Diachronic n-gram」
- 07 号图的 `fig.text` 英文副标必须含「(method ref: Evol — Diachronic n-gram frequency)」

**红线**：双向锚点缺一不可。

## 自检

- [ ] 每篇论文都有自己的 ### 三段
- [ ] 每个借鉴点都指向具体的 0X 号图或公式
- [ ] 借鉴形态覆盖 A/B/C/D 中至少 2 种
- [ ] 每张借鉴某论文方法的图，副标都含「method ref: <Paper>」
- [ ] 「最直接对应」的那篇论文（通常是最贴近本作业语料/方法的）单独标注，并放在末尾

## 如何选哪些论文是「最直接对应」

判定法：

> 如果不读这篇论文，本作业有没有任何一张图会做不出来？

回答"是"的，就是最直接对应。例：Paper 3 (Evol) 给了 Diachronic + Co-occurrence + Lexical Shift 三大可视化，本作业 07/08 号都是直接复刻——不读它，07/08 设计不出来。这就是最直接对应。
